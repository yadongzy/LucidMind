# 第七条：模块日志

```
每个模块一个独立日志文件，存放在 logs/ 目录下。
日志不是走形式——是给未来的自己和用户看的，必须看得懂。

日志文件命名：
  logs/brain.log          — Brain 核心流程
  logs/llm.log            — LLM 调用（请求、响应、耗时、错误）
  logs/tools.log          — 工具调用（参数、结果、耗时）
  logs/memory.log         — 记忆存取
  logs/stream.log         — 思维流事件
  logs/learning.log       — 经验学习
  logs/api.log            — API 请求

每条日志必须包含：
  时间 | 模块 | 动作 | 结果 | 详情（如有）

重点记录：
  - 每次 LLM 调用的输入摘要、输出摘要、耗时、token 用量
  - 每次工具调用的参数、返回结果、成功/失败
  - 每次错误的完整堆栈和根因分析
  - 每次反思：做了什么、结果如何、学到了什么

日志不能：
  - 记录完整的 API Key 或敏感信息
  - 只记「成功」不记过程
  - 用技术术语糊弄，要写人话
```
