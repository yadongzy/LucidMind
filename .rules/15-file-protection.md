# 第十五条：核心文件保护（防误操作铁律）

```
本条源于真实事故：AI未经确认删除了7个前端文件+多次修改api/main.py路由。

1. 核心文件清单（修改前必须声明+确认）
   - brain.py, brain_daemon.py, brain_meta.py
   - task_dispatcher.py
   - api/main.py
   - ports/ 下所有接口文件
   - frontend/ 下所有文件
   - frontend-v2/ 下所有文件
   - .rules/ 下所有规则文件（本文件除外，新增规则时可直接创建）

2. 禁止操作（无例外）
   - 禁止未经用户确认删除任何文件
   - 禁止未经用户确认修改前端路由指向
   - 禁止未经用户确认修改静态文件挂载路径
   - 禁止"顺便"修改核心文件（每个改动必须有明确目的）

3. 安全操作（无需确认）
   - 新建 adapters/ 下的文件（走第六条流程）
   - 新建 scripts/ 下的测试/验证脚本
   - 新建 docs/ 下的文档
   - 修改 tests/ 下的测试文件（但不能删除/弱化测试）

4. 违反处理
   - 立即停止当前操作
   - 向用户报告：改了什么、为什么改、影响范围
   - 等待用户指示：恢复 or 保留
   - 记录到 PROGRESS.md 作为事故记录
```
