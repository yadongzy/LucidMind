## 二、文献依据

### 2.1 arXiv 2505.16067 (2025.05)
**《How Memory Management Impacts LLM Agents: An Empirical Study of Experience-Following Behavior》**

核心发现（实证数据，3个不同Agent验证）：

**发现1：经验跟随效应 (Experience-Following Property)**
- 高输入相似度 → 高输出相似度
- Agent会严格复制检索到的经验行为
- 意义：错误经验被检索到 = 错误被复制

**发现2：错误传播 (Error Propagation)**
- add-all策略（存储所有经验）性能**持续下降**
- strict selective addition性能**持续上升**
- 2000次执行后差距超过10%

**发现3：选择性删除比选择性添加更重要**

| 策略 | EHRAgent准确率 | 内存大小 |
|------|---------------|---------|
| 不删除 | 38.89% | 1012 |
| 周期性删除 | 39.04% | 302 |
| 历史删除 | 42.65% | 784 |
| **组合删除** | **42.88%** | **248** |

组合删除：准确率+4%，内存-75%。

**发现4：Misaligned Experience Replay（错位经验回放）**
- 输入相似度高但输出相似度低的经验最有害
- 这类经验"看起来相关但实际误导"
- history-based deletion能有效识别和删除这类经验

### 2.2 Harvard D3 分析
> "Simply storing every experience leads to significantly worse outcomes."
> "Memory improvement is less about hoarding information than curating a high-quality knowledge base."

### 2.3 Mem0 (arXiv 2504.19413)
- 知识图谱架构用于Agent记忆
- 生产级可扩展长期记忆系统

## 三、对标分析：OpenClaw vs LucidMind

### 3.1 OpenClaw 记忆系统架构 (src/memory/, 78文件)

```
OpenClaw Memory Architecture:
├── manager.ts (20KB) — 核心管理器，SQLite + 向量索引
├── hybrid.ts — 向量×权重 + BM25×权重 混合检索
├── mmr.ts — Maximal Marginal Relevance 多样性重排
├── temporal-decay.ts — 指数时间衰减（半衰期30天）
├── query-expansion.ts — 查询扩展（停用词+中英文分词）
├── manager-search.ts — 向量搜索 + 关键词搜索
├── embeddings.ts — 多provider嵌入（OpenAI/Gemini/Voyage/本地）
├── session-files.ts — 会话文件管理
└── types.ts — 类型定义
```

关键设计：
- **SQLite持久化** + sqlite-vec向量扩展
- **混合检索**: `score = vectorWeight * vectorScore + textWeight * textScore`
- **时间衰减**: `score *= exp(-λ * ageInDays)`, λ = ln2/halfLifeDays
- **常青知识**: `isEvergreenMemoryPath()` — 核心知识不衰减
- **MMR重排**: `mmr = λ * relevance - (1-λ) * max_similarity_to_selected`

### 3.2 架构对比

| 维度 | OpenClaw | LucidMind | 差距 |
|------|----------|-----------|------|
| 存储 | SQLite + 向量索引 | JSON文件全量读写 | 致命差距 |
| 检索 | 向量余弦 + BM25混合 | BM25 + 可选向量(未启用) | 中等差距 |
| 时间衰减 | 指数衰减,半衰期30天,常青知识 | 指数衰减,半衰期60天 | 相近 |
| 多样性 | MMR重排(λ=0.7) | MMR重排(λ=0.7) | **已对齐** |
| 查询扩展 | 停用词 + 中英文分词 | 停用词 + 中文bigram | 相近 |
| 质量评估 | 无 | effectiveness追踪 | **LM领先** |
| 选择性添加 | 无 | 有去重(trigger合并) | **LM领先** |
| 选择性删除 | 无 | 有淘汰(超上限删最低效) | **LM领先** |
| Embedding | 多provider | 可选(实际未启用) | 关键缺失 |

### 3.3 LucidMind的独特优势
- **经验有效性追踪** — OpenClaw没有
- **选择性添加(去重)** — OpenClaw没有
- **淘汰机制** — OpenClaw没有
- **教学系统** — OpenClaw没有

## 四、三个致命缺陷

### 缺陷1：经验有效性闭环断裂

```python
# brain_learning.py:44 — _mark_lessons_effective()
# 只在 process() 成功/失败后调用
# 但 daemon 任务走 _execute_task()，不经过 process()
# 大脑90%的任务都是daemon执行的
# → 90%的经验永远不会被评估有效性
# → effectiveness 全部是 None
# → 淘汰机制形同虚设
```

### 缺陷2：无选择性删除机制

当前只有"超上限淘汰"（超过200条时删最低效的），没有主动删除低质量经验。
论文证明：组合删除（周期性+历史性）准确率+4%，内存-75%。

### 缺陷3：向量语义检索未实际启用

`vector_store.py` 代码已写好，`retrieval.py:206-230` 融合逻辑已写好，
但实际运行时 `get_vector_store().is_available()` 可能返回 False（模型未加载成功）。
纯BM25无法处理语义相似但词汇不同的查询。

## 五、加固方案（4个优先级）

### P0：修复经验有效性闭环 [最小改动，最大收益]

**问题**: daemon任务不经过process()，经验effectiveness永远是None
**方案**: 在brain_daemon.py的_execute_task成功/失败后调用_mark_lessons_effective()
**改动量**: ~10行
**预期效果**: 200条经验从"全部未验证"变为"有真实数据"，淘汰机制生效
**依据**: 论文Table 2 — 有可靠评估器时，history-based deletion准确率+4%

### P1：实施选择性删除 [论文核心发现]

**问题**: 经验只增不减，低质量经验持续污染
**方案**: 创建独立模块 `adapters/learning/memory_curator.py`
- **周期性删除**: 每24小时扫描，删除创建超过N天且effectiveness<0.3的经验
- **历史性删除**: 追踪每条经验被检索后的"输出效果"，连续3次低效果标记为misaligned并删除
- **组合删除**: 两种策略同时运行
**改动量**: 新建1个文件(~200行)
**预期效果**: 经验库从200条降到~80条高质量经验
**依据**: 论文数据 — 组合删除准确率+4%，内存-75%

### P2：确保向量语义检索可用 [解决语义匹配]

**问题**: 纯BM25无法匹配语义相似但用词不同的经验
**方案**: 确保vector_store使用Ollama本地embedding可靠工作
- 启动时预热embedding模型
- 增加重试和降级逻辑
**改动量**: ~20行修改
**预期效果**: "连接Ollama"能匹配到"与本地模型通信"

### P3：经验分层 [OpenClaw常青知识概念]

**问题**: 所有经验平等对待，策略级经验不应衰减
**方案**: 在json_lessons.py中增加tier字段
- **strategy**(策略级): 平台规则、方法论 — 永不衰减
- **fact**(事实级): 具体任务记录 — 正常衰减(60天半衰期)
- **temp**(临时级): 一次性上下文 — 快速衰减(7天半衰期)
**改动量**: ~30行修改
**预期效果**: 策略级经验永不遗忘，临时经验自动清理

## 六、实施路线图

```
Phase 1 (立即): P0 修复有效性闭环 + P1 选择性删除
  → 经验库从200条"未验证"变为~80条"已验证高质量"

Phase 2 (本周): P2 确保向量检索 + P3 经验分层
  → 语义匹配上线 + 策略级经验永不遗忘

Phase 3 (验证): 效果度量
  → 经验命中率、错误重复率、任务成功率
```
