## P0: 代码行数合规

### P0-1: brain_daemon.py 拆分 (405→≤300)

**分析**: brain_daemon.py 包含以下职责:
1. BrainDaemon类主体（OODA循环、任务执行、教学循环） — 核心
2. `_ingest_teacher_messages` + `_fast_learn_from_teacher` — 教师消息处理
3. `_execute_task` + `_handle_task_failure` + `_should_use_local` + `_get_tool_scope` — 任务执行
4. `_teaching_cycle` + `_execute_teaching_plan` — 教学相关

**方案**: 提取 `_execute_task` 相关方法到 `brain_task_executor.py` (新mixin)

- **新建**: `brain_task_executor.py` (~120行)
  - `_execute_task()`
  - `_handle_task_failure()`
  - `_should_use_local()`
  - `_get_tool_scope()`
- **修改**: `brain_daemon.py` — import并继承mixin
- **目标**: brain_daemon.py ≤ 290行

### P0-2: task_dispatcher.py 拆分 (484→≤300)

**分析**: task_dispatcher.py 包含:
1. 核心队列操作（enqueue/dequeue/complete/fail） — 必须保留

4. daily/monthly check标记 — 可拆出
5. get_queue_status — 可拆出

**方案**: 提取辅助函数到 `task_dispatcher_utils.py`

- **新建**: `task_dispatcher_utils.py` (~150行)
  - `compute_interval()`
  - `auto_expire()`

- **修改**: `task_dispatcher.py` — 核心queue操作保留
- **目标**: task_dispatcher.py ≤ 290行

## P1: 死代码清理

### P1-1: 从main.py移除无用工具注册

**当前** (api/main.py:88-91):
```python
tool_adapter = CompositeToolAdapter([
    ShellAdapter(), FileAdapter(), WebSearchAdapter(), SearchFilesAdapter(),
    DocumentAdapter(), BrowserToolAdapter(), ImageToolAdapter(), FileAnalyzeAdapter(),
    _sub_agent, _plugins, VisionAdapter(), TTSAdapter(), STTAdapter(),
    IntrospectAdapter(), TeachingAdapter(), GUIAutomationAdapter(),
    WeatherAdapter(), SystemMonitorAdapter(), SchedulerAdapter(), ClipboardAdapter(),
    NotificationAdapter(), DoubaoCommAdapter(), HWScannerAdapter(), DeepResearchAdapter()
])
```

**移除** (8个):
| 工具 | 移除原因 |
|------|---------|
| GUIAutomationAdapter | brain_awareness中禁止使用，pyautogui不稳定 |
| DoubaoCommAdapter | 依赖豆包桌面GUI操作，无法工作 |
| VisionAdapter | 依赖显示器+API，服务器环境无用 |
| TTSAdapter | 语音合成，未测试，非核心 |
| STTAdapter | 语音识别，未测试，非核心 |
| ClipboardAdapter | 剪贴板操作，未测试，非核心 |
| NotificationAdapter | 桌面通知，未测试，非核心 |
| PluginLoaderAdapter (_plugins) | plugins/为空，纯框架 |

**保留** (16个):
ShellAdapter, FileAdapter, WebSearchAdapter, SearchFilesAdapter,
DocumentAdapter, BrowserToolAdapter, ImageToolAdapter, FileAnalyzeAdapter,
SubAgentAdapter, IntrospectAdapter, TeachingAdapter, WeatherAdapter,
SystemMonitorAdapter, SchedulerAdapter, HWScannerAdapter, DeepResearchAdapter

**同时移除对应import语句。**

## P2: 功能激活

### P2-1: 灵魂进化激活

**问题**: soul_engine.evolve()从未被调用

**方案**: 在 `brain_engines.py` 的 `LearningEngine.maybe_learn()` 中添加进化触发:
```python
# 在学习引擎中，每日检查经验库是否有可进化的模式
if soul_engine:
    suggestions = soul_engine.analyze_patterns(lessons)
    for s in suggestions[:1]:  # 每次最多进化1条
        soul_engine.evolve(s["trigger"], s["suggested_rule"])
```

**修改文件**:
- `brain_engines.py`: LearningEngine.__init__接收soul_engine参数
- `brain_daemon.py`: 传递soul_engine给LearningEngine

**验证**: 重启后检查 `identity/soul_evolution.json` 是否有新条目

### P2-2: effectiveness虚高修正

**问题**: 每次process()成功（含简单问候）都标记经验为effective → 0.999虚标

**方案**: 只在涉及工具调用的对话中标记effective
```python
# brain.py:218-219 修改为:
# 只有发生工具调用时才标记经验有效（简单问候不算）
if tool_calls_happened:
    await self._mark_lessons_effective(True)
```

**修改文件**: `brain.py` — process()中添加tool_calls_happened标记

**验证**: 重启后新对话，简单问候不应改变effectiveness

### P2-3: 深度元认知超时修正

**问题**: deep_analyze超时5秒，DeepSeek通常>5秒 → 99%降级到规则引擎

**方案**: 超时从5秒→15秒，且对本地模型跳过深度分析（已实现）
```python
# metacognition.py:105-107
resp = await asyncio.wait_for(
    llm.chat([...], tools=None),
    timeout=15.0  # 从5.0改为15.0
)
```

**修改文件**: `metacognition.py`

**验证**: 发送复杂问题，观察是否出现深度分析（🧠 开头的详细思考）
