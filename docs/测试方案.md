## M1: 服务启动与健康检查

### M1-1: 服务启动
- **操作**: 在终端执行 `/opt/anaconda3/bin/python -m uvicorn api.main:app --host 0.0.0.0 --port 8000`
- **预期**: 启动成功，日志显示 Brain 单例创建、MCP 工具注入、通道启动
- **验证**: 终端无 Error 日志

### M1-2: 健康检查 API
- **操作**: 浏览器访问 `http://localhost:8000/api/health`
- **预期**: 返回 `{"status": "ok", "version": "0.1.0", "llm_available": true}`
- **验证**: status=ok, llm_available=true

### M1-3: 状态 API
- **操作**: 浏览器访问 `http://localhost:8000/api/status`
- **预期**: 返回包含 llm/tools/ports 的完整状态 JSON
- **验证**: tools 列表非空, ports 各项为 true

### M1-4: 前端页面加载
- **操作**: 浏览器访问 `http://localhost:8000`
- **预期**: 前端页面正常加载，显示左侧导航栏 + 对话页面
- **验证**: 无白屏，无 JS 错误

### M1-5: WebSocket 连接
- **操作**: 观察页面右上角连接状态指示器
- **预期**: 显示绿色/已连接状态
- **验证**: 状态显示 "Connected" 或绿色圆点

### M1-6: 心跳检测
- **操作**: 等待 30 秒观察心跳状态
- **预期**: 心跳正常，显示延迟时间
- **验证**: 无断连警告
