# LucidMind 灵魂系统完整指南

> 本文档详细介绍 LucidMind 的灵魂系统架构——包括身份定义、记忆存储、多用户隔离、秘密空间等所有相关文件和使用方法。

---

## 一、系统总览

LucidMind 的"灵魂"不是单一文件，而是一个**多层协作系统**：

```
身份层（identity/）    → 定义"我是谁"、"怎么行动"、"内心想法"
记忆层（memory/）      → 定义"我记得什么"、"怎么检索"
学习层（adapters/learning/） → 定义"我从错误中学到什么"
自省层（adapters/reflection/） → 定义"我对自己的观察"
配置层（brain_config.py + config/ + prompts/） → 行为参数和提示模板
大脑核心（brain.py）   → 把以上所有层拼装成系统提示词发送给 LLM
```

每次用户发消息时，`brain.py` 的 `_build_messages()` 方法按以下顺序拼装系统提示词：

```
CORE.md → SOUL.md → USER.md → profile_context → custom_prompts/*.md
→ 角色人格 → 知识技能 → 首次引导
→ 当前状态 → 目标 → 经验 → 自省
```

### 2.3 多用户身份目录

每个用户首次交互时，系统自动在以下路径创建个性化副本：

```
/Users/yadong/Documents/LucidMind/data/users/{user_id}/identity/
├── SOUL.md            ← 用户可自由编辑的灵魂
├── USER.md            ← 用户画像（称呼、偏好、规则）
├── BOOTSTRAP.md       ← 首次引导状态
├── custom_prompts/    ← 用户自定义提示词片段（任意 *.md 文件自动注入）
│   └── coding_style.md  ← 示例：编码风格规则
│   └── my_rules.md      ← 示例：个人特殊规则
└── personas/          ← 用户自定义人格
    └── teacher.md       ← 示例：教师模式
```

**关键规则：**
- `CORE.md` **永远从系统目录加载**，用户不可覆盖
- 用户目录下的 `SOUL.md` / `USER.md` 优先于系统默认模板
- `custom_prompts/` 下所有 `.md` 文件自动注入系统提示词
- 用户可以直接编辑文件，也可以通过 API 操作

## 九、使用说明

### 9.1 普通用户（对话中使用）

**不需要做任何事情。** 系统会在你首次对话时自动：
1. 创建你的个人身份目录
2. 从系统模板复制默认 SOUL.md / USER.md
3. 引导你完成首次设置

之后，你的 AI 会记住你的偏好，并按照你的个性化配置回应。

### 9.2 高级用户（直接编辑文件）

1. **修改你的 AI 性格**：编辑 `data/users/{你的ID}/identity/SOUL.md`
2. **修改你的画像**：编辑 `data/users/{你的ID}/identity/USER.md`
3. **添加自定义规则**：在 `data/users/{你的ID}/identity/custom_prompts/` 下创建任意 `.md` 文件
4. **创建自定义人格**：在 `data/users/{你的ID}/identity/personas/` 下创建 `.md` 文件

### 9.3 通过 API 操作

```bash
# 查看你的身份信息
curl http://localhost:8000/api/identity/my_user_id

# 更新你的灵魂
curl -X PUT http://localhost:8000/api/identity/my_user_id/soul \
  -H "Content-Type: application/json" \
  -d '{"content": "# 我的灵魂\n我是一个温柔的助手..."}'

# 添加自定义提示词
curl -X POST http://localhost:8000/api/identity/my_user_id/prompts \
  -H "Content-Type: application/json" \
  -d '{"name": "my_rules", "content": "## 我的规则\n- 总是用中文回答\n- 代码注释用英文"}'

# 添加自定义人格
curl -X POST http://localhost:8000/api/identity/my_user_id/personas \
  -H "Content-Type: application/json" \
  -d '{"name": "poet", "content": "# 诗人\n用诗意的语言回答每个问题"}'
```

### 9.4 系统管理员

- 编辑 `identity/CORE.md` → 修改**所有用户共享**的不可变规则
- 编辑 `identity/SOUL.md` → 修改**新用户的默认**灵魂模板
- 在 `identity/personas/` 下添加 `.md` 文件 → 添加系统预置人格

## 十、数据流图

```
用户发消息
    │
    ▼
brain.py: process()
    │
    ├── _current_user_id() ──→ 获取当前用户 ID
    │
    ├── UserProfileAdapter.get_context_prompt(user_id)
    │       └── data/profiles/{user_id}.json → profile_context
    │
    ├── UserIdentityManager.build_identity_prompt(user_id, profile_context)
    │       │
    │       ├── CORE.md（系统级，不可变）
    │       ├── SOUL.md（用户级，优先用户自定义）
    │       ├── USER.md（用户级，优先用户自定义）
    │       ├── profile_context（程序化用户偏好）
    │       └── custom_prompts/*.md（用户自定义片段）
    │
    ├── PersonaManager.get_persona_prompt()
    │       └── identity/personas/{name}.md
    │
    ├── get_prompt_skills_content()
    │       └── 知识型技能注入
    │
    ├── _build_self_awareness()
    │       └── 可用工具、模型、时间、环境
    │
    ├── GoalSystem.get_context_for_brain()
    │       └── data/goals.json
    │
    ├── _get_relevant_lessons()
    │       └── data/lessons.json 或 SQLite memory
    │
    └── ReflectionAdapter.get_reflection_text()
            └── 自省摘要

    ──→ 拼装为 system prompt ──→ 发送给 LLM
```
