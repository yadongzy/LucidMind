## 十、第三轮：多用户写入隔离修复（2026-03-01 11:27）

> 用户质问为什么发现了 bug 不修复。诚实回答：没有好理由，立即修复。

### 10-1: 修复 brain_learning.py 多用户写入 bug ✅

**bug:** `_maybe_promote_to_profile()` 将用户纠正规则写入系统级 `identity/USER.md` 模板，而非 per-user 文件。多用户场景下一个用户的纠正会污染所有用户的模板。

**修复：**
```python
# Before (bug):
user_path = pathlib.Path(__file__).parent / "identity" / "USER.md"

# After (fixed):
user_id = self._current_user_id()
user_dir = self._identity_mgr.ensure_user_dir(user_id)
user_path = user_dir / "USER.md"
```

**同时添加：** 写入后清除 `_identity_mgr._cache` 对应条目，确保下次 `build_identity_prompt()` 读到最新内容。

### 10-2: 全量写入链路审计 ✅

| 写入路径 | 目标文件 | 多用户安全 | 说明 |
|---------|---------|-----------|------|
| `user_identity.py:update_soul()` | per-user SOUL.md | ✅ | 正确 |
| `user_identity.py:update_user_profile()` | per-user USER.md | ✅ | 正确 |
| `user_identity.py:add_custom_prompt()` | per-user custom_prompts/ | ✅ | 正确 |
| `user_identity.py:add_user_persona()` | per-user personas/ | ✅ | 正确 |
| `soul_engine.py:evolve()` | system identity/SOUL.md | ✅ | **设计正确**：Daemon 全局运行，进化规则作为新用户模板基线。现有用户已有独立副本，不受影响 |
| `brain_learning.py:_maybe_promote_to_profile()` | ~~system identity/USER.md~~ → per-user | ✅ | **本轮修复** |
| `api/identity_api.py` PUT 端点 | 通过 user_identity.py | ✅ | 正确 |

**结论：** 所有 7 条写入路径均已验证多用户安全。无残留隔离风险。
