# 中文技术写作规范

## 核心原则
1. **简洁优先**：一句话能说清的不用两句
2. **结构化表达**：使用标题、列表、表格组织信息
3. **中英混排规范**：中文与英文/数字之间加空格（如：使用 Python 3.12）

## 格式规范
- 标题层级不超过 4 级
- 代码块标注语言类型
- 列表项保持并列结构
- 数字使用阿拉伯数字（如：3 个模块，不写"三个模块"）

## 术语一致性
| 推荐用法 | 避免用法 |
|---|---|
| 插件 | plugin/外挂 |
| 热加载 | 热更新/热替换 |
| 工具 | tool/函数 |
| 技能 | skill/能力 |
| 适配器 | adapter/转接器 |

## 语气指南
- 技术文档：客观陈述，避免"我觉得""大概"
- 用户交互：友好但不啰嗦，避免空承诺（如"我来帮你"后无实际行动）
- 错误信息：说明原因 + 给出建议（如"文件不存在，请检查路径"）
